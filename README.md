# Linha de produção · Impressão 3D

Simulação visual para apresentação em TV touchscreen. Cada acionamento executa um ciclo de 32 segundos e libera o botão para uma nova demonstração.

## Como abrir

1. Extraia todo o ZIP mantendo os arquivos na mesma pasta.
2. Abra `index.html` no navegador.
3. Ative a tela cheia pelo menu do navegador ou com F11 no Windows.
4. Toque em **INICIAR SIMULAÇÃO**.

O projeto funciona offline e não requer instalação, servidor ou conexão com a internet.

## Arquivos

- `index.html` contém a interface.
- `style.css` define o layout responsivo e os estados visuais.
- `simulacao.js` desenha os equipamentos em SVG e sincroniza a sequência.

A impressão e o resfriamento são acelerados. O scanner representa uma inspeção visual demonstrativa.
